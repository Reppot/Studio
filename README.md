# Studio

Сайт веб-студии: интерактивная WebGL-композиция, анимации прокрутки, услуги и портфолио.

## Структура

- `dist/index.html` — главная страница.
- `dist/sindaris.html` — кейс SINDARIS Terminal.
- `dist/styles.css` — стили и адаптивная вёрстка.
- `dist/script.js` — интерактивность страницы.
- `dist/hero-scene.js` — WebGL-сцена без внешних библиотек.
- `dist/case-gallery.js` — анимация скриншотов, переключение галереи и увеличение до 100%.
- `dist/assets/sindaris/` — реальные снимки действующего приложения: управление, MPF и карта планирования.

## Локальный просмотр

Из корня репозитория:

```sh
python -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Сборка и установка зависимостей не требуются.

## Публикация

Каталог `dist` готов для статического хостинга. Текущий приватный прототип опубликован в Sites: https://studio-web-prototype.reppot-6.chatgpt.site.

Репозиторий содержит исходники сайта без учётных данных и настроек доступа Sites. Публикация в Sites выполняется отдельно.

Кейс подготовлен по исходникам https://github.com/Reppot/Sandalis-web-v2.0. Реальные скриншоты сняты с https://sandalis-web-v2-0.onrender.com/ в браузере: управление ролями, пример расчёта MPF и карта планирования. Личный профиль и список участников в кадры не включены. Обложка использует эти снимки с анимацией глубины; в кейсе есть переключение экранов и просмотр в масштабе 100%. Статистика использования не заявляется.

Форма заявки демонстрационная, отправка данных не подключена. Для анимаций предусмотрены пауза, режим уменьшения движения и статическая замена при отсутствии WebGL.
