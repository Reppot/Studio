# Studio

Сайт веб-студии с интерактивной WebGL-композицией, анимациями прокрутки, услугами и портфолио.

## Структура

- `dist/index.html` — главная страница и одна карточка SINDARIS Terminal.
- `dist/styles.css` — стили и адаптивная вёрстка.
- `dist/script.js` — интерактивность главной.
- `dist/hero-scene.js` — WebGL-сцена без внешних библиотек.
- `dist/case-preview.js` — анимация областей внутри карточки и пауза.
- `dist/assets/sindaris/home.png` — единственный снимок: фрагмент главной SINDARIS, 1002 × 480 пикселей.
- `dist/sindaris.html` — переход со старого адреса к карточке портфолио.

## Локальный просмотр

Из корня репозитория:

```sh
python -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Сборка и установка зависимостей не требуются.

## Карточка SINDARIS

Исходный проект: https://github.com/Reppot/Sandalis-web-v2.0.
Снимок сделан с главной https://sandalis-web-v2-0.onrender.com/: раздел «Склад и заказы».
Это один фрагмент настоящего интерфейса, сохранённый в PNG без дополнительного JPEG-перекодирования.
Изображение в карточке не увеличивается сверх исходного размера, не поворачивается и не размывается.
Анимируются отдельные рамки и маркеры поверх интерфейса. Предусмотрены пауза, реакция на указатель и режим уменьшения движения.
Карточка открывает действующий сайт проекта.
